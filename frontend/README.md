# Frontend — TrabajoSocial

React 19 + TypeScript + Vite + Tailwind CSS v4. Consulte el [README principal](../README.md) para la arquitectura y la puesta en marcha.

```bash
npm install
npm run dev     # http://localhost:5173 (o el siguiente puerto libre); /api se redirige a http://localhost:5080
npm run build   # chequeo de tipos + build de producción
npm run lint    # oxlint
```
